NoteProject API

API Reference

Every endpoint of nujabes, ichiro and lonzo.

Overview

Base URLhttps://notes.localhost/api (development, through Caddy)
AuthenticationLog in with POST /auth/login; the session cookie then goes with every request. Caddy checks it with nujabes and passes X-User-Id on to ichiro and lonzo. Anything a client sends in that header is replaced.
FormatJSON, except the event stream of POST /chat.
Errors{"detail": "note not found"}; 422 from request validation has a list in detail.
HealthGET /health is internal: each service answers it on port 8000, and Caddy doesn't route it.
